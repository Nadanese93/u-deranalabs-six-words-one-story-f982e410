# Six Words, One Story

A complete story in exactly six words, written by `main.ts` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

> Grandfather's boat returned. He never did.

Six words, 42 characters. A fisherman's boat comes home without him — a whole life at sea, ended in the gap between the two sentences. What the sea did is left unsaid.

## Run

```sh
node main.ts
```

Node 22, standard library only. Deterministic: the same bytes on every run.
